# @rightandabove/communication-email-core

Shared contracts for transactional email: types, Zod schemas, command and event names. Depends only on `zod`.

**Install:** `npm i @rightandabove/communication-email-core`

Used by [`@rightandabove/communication-email-nest`](https://www.npmjs.com/package/@rightandabove/communication-email-nest) and [`@rightandabove/communication-email-react`](https://www.npmjs.com/package/@rightandabove/communication-email-react).

## Sibling packages

| Package | Role |
| --- | --- |
| `communication-email-core` | This package — schemas & shared types |
| `@rightandabove/communication-email-nest` | NestJS SMTP / CQRS sender |
| `@rightandabove/communication-email-react` | Headless React passthrough |

Not in scope: IMAP, campaigns, unsubscribe, bounce analytics.
