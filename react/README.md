# @rightandabove/communication-email-react

Headless React passthrough for the communication-email stack. It does **not** send mail and does **not** expose SMTP — use [`@rightandabove/communication-email-nest`](https://www.npmjs.com/package/@rightandabove/communication-email-nest) on the server.

**Install:** `npm i @rightandabove/communication-email-react`

Peer dep: `react` (^18 or ^19). Depends on [`@rightandabove/communication-email-core`](https://www.npmjs.com/package/@rightandabove/communication-email-core).

## Sibling packages
